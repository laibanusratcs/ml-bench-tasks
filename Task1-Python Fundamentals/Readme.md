## 1. Python Practice Problems

This folder contains practice exercises covering basic Python data structures and their operations.

**Topics covered:**

- **Lists:** Finding the largest and second largest numbers, reversing lists, removing duplicates, and finding common elements.
- **Tuples:** Counting occurrences and converting tuples into lists and vice versa.
- **Sets:** Finding unique values, union, and intersection.
- **Dictionaries:** Calculating average marks, counting word frequency, and working with student records.

## 2. Student Grading System

A simple console-based program that takes student information and subject marks, calculates the average, and assigns a grade based on the marks.

## 3. Student Record Management System

A basic console-based application for managing student records. It includes options to add students and view all stored student records.
